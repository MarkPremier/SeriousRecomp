Beta v0.1.5 of the Serious Sam (Xbox, USA) static recompilation for Windows.

You need your own original Xbox **USA** game files. Extract the ZIP into one
folder and keep `d3dcompiler_ms.dll` beside `serious_sam_recomp.exe`. When
updating, keep your existing game folder, saves and settings. No game data or
personal settings are included.

**Changes since Beta v0.1.4**

- Added a remembered single-player **Cheats** page in the main menu, with a
  default-off **Show in pause menu** option.
- Corrected the session-property check that prevented cheats from working in
  existing single-player saves.
- Cheats and Quit Game now slide in from the sides with the other main-menu
  entries, including when returning to the menu.
- Added an optional **100% walker shadow** visibility trial. Run
  `tools\test-walker-shadows.cmd` to enable it. Normal executable launches
  keep the original shadow strength. This affects biomechanical walkers;
  other enemies keep their native shadows. The texture's soft edge, fog and
  depth testing are preserved.
- F11 captures include each simple-shadow corner, projection and intensity
  to help investigate rendering reports.

**Validation**

All 15 title regression tests pass, including original single-player session
initializers, damage/inventory helpers, menu animation and shadow-trial scope
and guest calling-convention checks. A copied Suburbs save verifies health,
armor and ammunition cheats. The packaged executable and its included shadow
launcher were checked in that save; its foreground walker shadow records full
RGB strength. Testing uses private save/settings copies. Broader cheat-effect
and full-game validation remain pending.

**Known issues**

- Rare boot-movie freezes and the previously reproduced NVIDIA shader/compiler
  failure with an empty cache remain under investigation.
- Other historical firing or level-loading crashes are not all confirmed fixed.
- The stronger walker shadows are an optional visibility adjustment; original
  Xbox visual parity has not been established.
- The reported Suburbs floor texture/lighting seam remains unresolved.
- The main menu has no music in the original game.

Windows 10/11 64-bit, a Direct3D 11 GPU and the Visual C++ x64 runtime are
required. For crashes or freezes, include `serious_sam_log.txt`. F11 captures
beside the executable help with rendering reports.
